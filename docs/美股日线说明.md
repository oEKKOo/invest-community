# 获取美股日K线数据说明

## 1. 文档目标

本文档用于整理 **Tushare 美股日 K 线获取方案**，将以下 3 个接口整合为一套完整的数据获取链路：

- `us_basic`：获取美股股票基础信息
- `us_tradecal`：获取美股交易日历
- `us_daily`：获取美股日线行情

适用场景：

- 初始化美股股票列表
- 根据交易日历判断某天是否开市
- 批量拉取某个交易日的全部美股日 K 线
- 拉取单只美股一段时间内的历史日线
- 为后续扩展美股行情同步任务、K 线入库、收益计算提供基础文档

---

## 2. 接口总览

| 接口名 | 用途 | 说明 |
|---|---|---|
| `us_basic` | 获取美股列表信息 | 可获取美股股票基础资料，支持分页提取 |
| `us_tradecal` | 获取美股交易日历 | 用于判断某一天是否为交易日，以及获取前一个交易日 |
| `us_daily` | 获取美股日线行情 | 获取美股历史日线及每日行情，是核心接口 |

---

## 3. 美股列表接口：us_basic

### 3.1 接口说明

**接口名**：`us_basic`  
**描述**：获取美股列表信息  
**单次限制**：最大 6000 条，可分页提取  
**积分要求**：120 积分可以试用，5000 积分有正式权限

### 3.2 输入参数

| 名称 | 类型 | 必选 | 描述 | 示例 |
|---|---|---|---|---|
| `ts_code` | str | N | 股票代码 | `AAPL`（苹果） |
| `classify` | str | N | 股票分类 | `ADR` / `GDR` / `EQ` |
| `offset` | str | N | 开始行数 | `1`：第一行 |
| `limit` | str | N | 每页最大行数 | `500`：每页 500 行 |

### 3.3 输出参数

| 名称 | 类型 | 描述 |
|---|---|---|
| `ts_code` | str | 美股代码 |
| `name` | str | 中文名称 |
| `enname` | str | 英文名称 |
| `classify` | str | 分类：ADR / GDR / EQ |
| `list_date` | str | 上市日期 |
| `delist_date` | str | 退市日期 |

### 3.4 调用示例

```python
import tushare as ts

pro = ts.pro_api()

# 获取默认美国股票基础信息，单次 6000 行
df = pro.us_basic()
```

### 3.5 数据示例

```python
     ts_code  name classify list_date delist_date
0       ONCY  None      EQT  20011005        None
1       SCCO  None      EQT  19950124        None
```

### 3.6 作用说明

`us_basic` 主要用于：

1. 初始化美股股票主表
2. 建立 `ts_code` 与股票名称、分类、上市日期的映射
3. 后续为 `us_daily` 提供股票代码来源
4. 支持分页同步全部美股股票池

> 说明：你提供的字段示例中分类描述为 `ADR/GDR/EQ`，而数据示例中出现的是 `EQT`。这部分建议实际调用接口后再确认项目中应以哪种枚举为准。

## 4. 美股交易日历接口：us_tradecal

### 4.1 接口说明

**接口名**：`us_tradecal`  
**描述**：获取美股交易日历信息  
**单次限制**：最大 6000 条，可根据日期区间获取

### 4.2 输入参数

| 名称 | 类型 | 必选 | 描述 | 示例 |
|---|---|---|---|---|
| `start_date` | str | N | 开始日期 | `20200101` |
| `end_date` | str | N | 结束日期 | `20200701` |
| `is_open` | str | N | 是否交易 | `0`：休市，`1`：交易 |

### 4.3 输出参数

| 名称 | 类型 | 描述 |
|---|---|---|
| `cal_date` | str | 日历日期 |
| `is_open` | int | 是否交易：`0` 休市，`1` 交易 |
| `pretrade_date` | str | 上一个交易日 |

### 4.4 调用示例

```python
import tushare as ts

pro = ts.pro_api()

df = pro.us_tradecal(start_date='20200101', end_date='20200701')
```

### 4.5 数据示例

```python
     cal_date  is_open pretrade_date
0    20200701        1      20200630
1    20200630        1      20200629
2    20200629        1      20200626
```

### 4.6 作用说明

`us_tradecal` 主要用于：

1. 判断某天美股市场是否开市
2. 在同步日线前，先确认目标日期是否为交易日
3. 获取上一个交易日，辅助增量同步逻辑
4. 避免在休市日调用 `us_daily` 造成无效请求

## 5. 美股日线接口：us_daily

### 5.1 接口说明

**接口名**：`us_daily`  
**描述**：获取美股行情（未复权），包括全部股票全历史行情，以及重要的市场和估值指标  
**单次限制**：最大 6000 行数据，可根据日期参数循环提取；开通正式权限后也可支持分页提取全部历史  
**权限要求**：120 积分可以试用查看数据，正式权限请参考 Tushare 权限说明

### 5.2 输入参数

| 名称 | 类型 | 必选 | 描述 |
|---|---|---|---|
| `ts_code` | str | N | 股票代码（例如 `AAPL`） |
| `trade_date` | str | N | 交易日期（`YYYYMMDD`） |
| `start_date` | str | N | 开始日期（`YYYYMMDD`） |
| `end_date` | str | N | 结束日期（`YYYYMMDD`） |

### 5.3 输出参数

| 名称 | 类型 | 描述 |
|---|---|---|
| `ts_code` | str | 股票代码 |
| `trade_date` | str | 交易日期 |
| `close` | float | 收盘价 |
| `open` | float | 开盘价 |
| `high` | float | 最高价 |
| `low` | float | 最低价 |
| `pre_close` | float | 昨收价 |
| `change` | float | 涨跌额 |
| `pct_change` | float | 涨跌幅 |
| `vol` | float | 成交量 |
| `amount` | float | 成交额 |
| `vwap` | float | 平均价 |
| `turnover_ratio` | float | 换手率 |
| `total_mv` | float | 总市值 |
| `pe` | float | PE |
| `pb` | float | PB |

### 5.4 调用示例

```python
import tushare as ts

pro = ts.pro_api()

# 获取单只美股一段时间内的日线
df = pro.us_daily(ts_code='AAPL', start_date='20190101', end_date='20190904')

# 获取某一个交易日的全部美股
df = pro.us_daily(trade_date='20190904')
```

### 5.5 数据示例

```python
    ts_code trade_date   close    open    high     low pre_close pct_change       vol              amount    vwap
0      AAPL   20190904  209.19  208.39  209.48  207.32    205.70       1.70  19216821   4008342529.970000  208.59
1      AAPL   20190903  205.70  206.43  206.98  204.22    208.74      -1.46  20059575   4120106317.760000  205.39
```

### 5.6 作用说明

`us_daily` 是美股行情同步的核心接口，主要用于：

1. 拉取单只美股历史日线
2. 拉取某一交易日全部美股日线
3. 同步每日行情增量
4. 为 K 线图、收益计算、行情列表提供基础数据
5. 提供部分估值指标字段，如 `pe`、`pb`、`total_mv`

## 6. 推荐的数据获取链路

将三个接口串起来后，推荐采用以下流程：

### 6.1 初始化阶段

#### 第一步：拉取美股股票列表
使用 `us_basic()` 获取美股股票基础信息：

```python
df_basic = pro.us_basic()
```

如单次结果不足，可结合 `offset` 和 `limit` 分页拉取。

用途：

- 初始化资产主表
- 保存 `ts_code`、`name`、`enname`、`classify`、`list_date` 等字段
- 后续同步日线时作为股票池

---

### 6.2 日常同步阶段

#### 第二步：先判断今天是否开市
使用 `us_tradecal()` 检查目标日期是否为交易日：

```python
df_cal = pro.us_tradecal(start_date='20250101', end_date='20250110')
```

如果某一天 `is_open = 1`，说明该天是交易日，可以继续调用 `us_daily`。

---

#### 第三步：拉取当日全部美股日线
如果要做每日增量同步，优先使用：

```python
df_daily = pro.us_daily(trade_date='20250110')
```

这种方式适合：

- 每日定时同步
- 收盘后批量更新全市场美股行情
- 减少逐只股票遍历调用的复杂度

> 注意：由于 `us_daily` 单次最大 6000 行，如果某一交易日返回股票数超过限制，需结合正式权限和分页能力，或按股票分批拉取。

---

### 6.3 历史补数阶段

#### 第四步：按股票拉取历史日线
如果需要补历史数据，可以按股票逐个拉取：

```python
df_hist = pro.us_daily(
    ts_code='AAPL',
    start_date='20240101',
    end_date='20250110'
)
```

这种方式适合：

- 单股历史补数
- 个别股票修复数据缺失
- 新增股票时补全历史 K 线

---

## 7. 推荐的实际使用策略

### 7.1 股票列表同步策略
- 周期性同步 `us_basic`
- 支持按 `classify` 分类同步
- 如数据量过大，使用 `offset + limit` 分页拉取

### 7.2 交易日判断策略
- 日线同步前，先调用 `us_tradecal`
- 如果当天不开市，则跳过 `us_daily`
- 可使用 `pretrade_date` 辅助查找上一个交易日

### 7.3 日线同步策略
推荐分两类：

#### 方案 A：每日增量
按交易日调用：

```python
pro.us_daily(trade_date='YYYYMMDD')
```

优点：

- 一次拉取当日市场数据
- 适合定时任务
- 更适合批量入库

风险点：

- 若全市场数据量超过单次限制，需要分页或拆分同步策略

#### 方案 B：历史补数
按股票调用：

```python
pro.us_daily(ts_code='AAPL', start_date='YYYYMMDD', end_date='YYYYMMDD')
```

优点：

- 适合修复缺失数据
- 适合首次初始化单股历史行情
- 便于控制每次请求规模

## 8. 示例代码：获取美股日 K 线完整流程

```python
import tushare as ts

TOKEN = '你的 tushare token'
ts.set_token(TOKEN)
pro = ts.pro_api()

# 1. 获取美股基础信息
df_basic = pro.us_basic()
print('美股数量:', len(df_basic))

# 2. 获取交易日历，判断目标日期是否开市
target_date = '20250110'
df_cal = pro.us_tradecal(start_date=target_date, end_date=target_date)

if not df_cal.empty and int(df_cal.iloc[0]['is_open']) == 1:
    print(f'{target_date} 为交易日，开始拉取日线')

    # 3. 获取该交易日全部美股日线
    df_daily = pro.us_daily(trade_date=target_date)
    print('当日日线数量:', len(df_daily))
    print(df_daily.head())
else:
    print(f'{target_date} 不是交易日，跳过同步')
```

## 10. 开发注意事项

### 10.1 权限限制
- `us_basic`：120 积分可试用，5000 积分有正式权限
- `us_daily`：120 积分可试用，完整历史与更强能力依赖正式权限
- 开发前应先确认当前 Tushare 账号权限是否满足要求

### 10.2 数据特点
- `us_daily` 为**未复权**行情
- 如果后续要做前复权 / 后复权展示，需要额外确认 Tushare 是否提供对应美股复权支持或自行处理

### 10.3 单次限制
- `us_basic`：单次最大 6000，可分页提取
- `us_tradecal`：单次最大 6000
- `us_daily`：单次最大 6000，可根据日期循环提取
- 全市场同步时要关注单日返回总量是否超限

### 10.4 同步策略建议
- 股票列表：低频同步
- 交易日历：按需同步或预拉取全年
- 日线行情：每日增量 + 历史补数双策略

### 10.5 待确认项
以下内容建议你在实际调用接口后确认：

1. `classify` 的枚举值是否统一为 `ADR/GDR/EQ`，还是存在 `EQT`
2. `us_daily` 在正式权限下的分页参数与实际返回方式
3. 全市场某一日行情是否会超过单次 6000 行限制
4. `amount` 的币种与精度在项目中是否需要统一换算

---

## 11. 最终结论

如果你的目标是**获取美股日 K 线并接入项目后端**，推荐采用以下标准流程：

1. 用 `us_basic` 获取美股列表，建立股票池  
2. 用 `us_tradecal` 判断目标日期是否开市  
3. 用 `us_daily(trade_date=...)` 获取某交易日全市场美股日线  
4. 用 `us_daily(ts_code=..., start_date=..., end_date=...)` 做历史补数  
5. 入库时以 `(ts_code, trade_date)` 作为唯一键，避免重复写入  

这套方案适合：

- 美股日线初始化
- 每日自动同步
- 后续扩展 K 线图
- 投资组合估值
- 收益统计
- 美股行情模块开发
