# 获取港股日线数据说明

## 1. 文档目标

本文档用于整理 **Tushare 港股日线获取方案**，将以下 3 个接口整合为一套完整的数据获取链路：

- `hk_basic`：获取港股股票基础信息
- `hk_tradecal`：获取港股交易日历
- `hk_daily`：获取港股日线行情

适用场景：

- 初始化港股股票列表
- 根据交易日历判断某天是否开市
- 批量拉取某个交易日的全部港股日线
- 拉取单只港股一段时间内的历史日线
- 为后续扩展港股行情同步任务、K 线入库、收益计算提供基础文档

---

## 2. 接口总览

| 接口名 | 用途 | 说明 |
|---|---|---|
| `hk_basic` | 获取港股列表信息 | 可获取全部在交易、退市、暂停上市的港股基础资料 |
| `hk_tradecal` | 获取港股交易日历 | 用于判断某一天是否为交易日，以及获取前一个交易日 |
| `hk_daily` | 获取港股每日行情 | 获取港股历史日线及每日增量行情，是核心接口 |

---

## 3. 港股列表接口：hk_basic

### 3.1 接口说明

**接口名**：`hk_basic`  
**描述**：获取港股列表信息  
**数量**：单次可提取全部在交易的港股列表数据  
**积分要求**：用户至少需要 **2000 积分**

### 3.2 输入参数

| 名称 | 类型 | 必选 | 描述 |
|---|---|---|---|
| `ts_code` | str | N | TS 代码 |
| `list_status` | str | N | 上市状态：`L` 上市，`D` 退市，`P` 暂停上市，默认 `L` |

### 3.3 输出参数

| 名称 | 类型 | 描述 |
|---|---|---|
| `ts_code` | str | TS 代码 |
| `name` | str | 股票简称 |
| `fullname` | str | 公司全称 |
| `enname` | str | 英文名称 |
| `cn_spell` | str | 拼音 |
| `market` | str | 市场类别 |
| `list_status` | str | 上市状态 |
| `list_date` | str | 上市日期 |
| `delist_date` | str | 退市日期 |
| `trade_unit` | float | 交易单位 |
| `isin` | str | ISIN 代码 |
| `curr_type` | str | 货币代码 |

### 3.4 调用示例

```python
import tushare as ts

pro = ts.pro_api()

# 获取全部可交易港股基础信息
df = pro.hk_basic()

# 获取全部退市港股基础信息
df = pro.hk_basic(list_status='D')
```

### 3.5 数据示例

```python
       ts_code             name  ...          isin curr_type
0     00001.HK               长和  ...  KYG217651051       HKD
1     00002.HK             中电控股  ...  HK0002007356       HKD
2     00003.HK           香港中华煤气  ...  HK0003000038       HKD
```

### 3.6 作用说明

`hk_basic` 主要用于：

1. 初始化港股股票主表
2. 建立 `ts_code` 与股票名称、市场、币种的映射
3. 后续为 `hk_daily` 提供股票代码来源
4. 过滤仅上市股票，避免对退市股票重复抓取

---

## 4. 港股交易日历接口：hk_tradecal

### 4.1 接口说明

**接口名**：`hk_tradecal`  
**描述**：获取港股交易日历  
**单次限制**：最大 2000 条  
**权限要求**：用户累计 **2000 积分** 才可调取

### 4.2 输入参数

| 名称 | 类型 | 必选 | 描述 |
|---|---|---|---|
| `start_date` | str | N | 开始日期 |
| `end_date` | str | N | 结束日期 |
| `is_open` | str | N | 是否交易：`0` 休市，`1` 交易 |

### 4.3 输出参数

| 名称 | 类型 | 描述 |
|---|---|---|
| `cal_date` | str | 日历日期 |
| `is_open` | int | 是否交易：`0` 休市，`1` 交易 |
| `pretrade_date` | str | 上一个交易日 |

### 4.4 调用示例

```python
import tushare as ts

pro = ts.pro_api()

df = pro.hk_tradecal(start_date='20200101', end_date='20200708')
```

### 4.5 数据示例

```python
     cal_date     is_open pretrade_date
0    20200708        1      20200707
1    20200707        1      20200706
2    20200706        1      20200703
```

### 4.6 作用说明

`hk_tradecal` 主要用于：

1. 判断某天港股市场是否开市
2. 在同步日线前，先确认目标日期是否为交易日
3. 获取上一个交易日，辅助增量同步逻辑
4. 避免在休市日调用 `hk_daily` 造成无效请求

---

## 5. 港股日线接口：hk_daily

### 5.1 接口说明

**接口名**：`hk_daily`  
**描述**：获取港股每日增量和历史行情，每日 **18 点左右** 更新当日数据  
**单次限制**：最大提取 **5000 行**，可多次提取，总量不限制  
**权限要求**：该接口需要**单独开通权限**

### 5.2 输入参数

| 名称 | 类型 | 必选 | 描述 |
|---|---|---|---|
| `ts_code` | str | N | 股票代码 |
| `trade_date` | str | N | 交易日期 |
| `start_date` | str | N | 开始日期 |
| `end_date` | str | N | 结束日期 |

### 5.3 输出参数

| 名称 | 类型 | 描述 |
|---|---|---|
| `ts_code` | str | 股票代码 |
| `trade_date` | str | 交易日期 |
| `open` | float | 开盘价 |
| `high` | float | 最高价 |
| `low` | float | 最低价 |
| `close` | float | 收盘价 |
| `pre_close` | float | 昨收价 |
| `change` | float | 涨跌额 |
| `pct_chg` | float | 涨跌幅(%) |
| `vol` | float | 成交量(股) |
| `amount` | float | 成交额(元) |

### 5.4 调用示例

```python
import tushare as ts

pro = ts.pro_api()

# 获取单只港股一段时间内的日线
df = pro.hk_daily(ts_code='00001.HK', start_date='20190101', end_date='20190904')

# 获取某一个交易日的全部港股日线
df = pro.hk_daily(trade_date='20190904')
```

### 5.5 数据示例

```python
      ts_code trade_date   open  ...  pct_chg         vol        amount
0    00001.HK   20190904  66.90  ...     3.45   8212577.0  5.619534e+08
1    00001.HK   20190903  66.40  ...    -0.52   3905632.0  2.598397e+08
2    00001.HK   20190902  67.50  ...    -0.71   6547427.0  4.397896e+08
3    00001.HK   20190830  69.60  ...    -0.73   7731576.0  5.299299e+08
```

### 5.6 作用说明

`hk_daily` 是港股行情同步的核心接口，主要用于：

1. 拉取单只港股历史日线
2. 拉取某一交易日全部港股日线
3. 同步每日收盘后的增量行情
4. 为 K 线图、收益计算、行情列表提供基础数据

## 6. 推荐的数据获取链路

将三个接口串起来后，推荐采用以下流程：

### 6.1 初始化阶段

#### 第一步：拉取港股股票列表
使用 `hk_basic()` 获取全部上市港股：

```python
df_basic = pro.hk_basic(list_status='L')
```

用途：

- 初始化资产主表
- 保存 `ts_code`、`name`、`market`、`curr_type` 等基础字段
- 后续同步日线时作为股票池

---

### 6.2 日常同步阶段

#### 第二步：先判断今天是否开市
使用 `hk_tradecal()` 检查目标日期是否为交易日：

```python
df_cal = pro.hk_tradecal(start_date='20250101', end_date='20250110')
```

如果某一天 `is_open = 1`，说明该天是交易日，可以继续调用 `hk_daily`。

---

#### 第三步：拉取当日全部港股日线
如果要做每日增量同步，优先使用：

```python
df_daily = pro.hk_daily(trade_date='20250110')
```

这种方式适合：

- 每日定时同步
- 收盘后批量更新全市场港股行情
- 减少逐只股票遍历调用的复杂度

---

### 6.3 历史补数阶段

#### 第四步：按股票拉取历史日线
如果需要补历史数据，可以按股票逐个拉取：

```python
df_hist = pro.hk_daily(
    ts_code='00001.HK',
    start_date='20240101',
    end_date='20250110'
)
```

这种方式适合：

- 单股历史补数
- 个别股票修复数据缺失
- 新增股票时补全历史 K 线

---

## 7. 推荐的实际使用策略

### 7.1 股票列表同步策略
- 每周或每天同步一次 `hk_basic`
- 默认拉取 `list_status='L'`
- 如需维护历史退市股票，可额外拉取 `D`

### 7.2 交易日判断策略
- 日线同步前，先调用 `hk_tradecal`
- 如果当天不开市，则跳过 `hk_daily`
- 可使用 `pretrade_date` 辅助查找上一个交易日

### 7.3 日线同步策略
推荐分两类：

#### 方案 A：每日增量
收盘后调用：

```python
pro.hk_daily(trade_date='YYYYMMDD')
```

优点：

- 一次拉取全市场
- 适合批量入库
- 更适合定时任务

#### 方案 B：历史补数
按股票调用：

```python
pro.hk_daily(ts_code='00001.HK', start_date='YYYYMMDD', end_date='YYYYMMDD')
```

优点：

- 适合修复缺失数据
- 适合首次初始化单股历史行情

## 8. 示例代码：获取港股日线完整流程

```python
import tushare as ts

TOKEN = '你的 tushare token'
ts.set_token(TOKEN)
pro = ts.pro_api()

# 1. 获取港股基础信息
df_basic = pro.hk_basic(list_status='L')
print('港股数量:', len(df_basic))

# 2. 获取交易日历，判断目标日期是否开市
target_date = '20250110'
df_cal = pro.hk_tradecal(start_date=target_date, end_date=target_date)

if not df_cal.empty and int(df_cal.iloc[0]['is_open']) == 1:
    print(f'{target_date} 为交易日，开始拉取日线')

    # 3. 获取该交易日全部港股日线
    df_daily = pro.hk_daily(trade_date=target_date)
    print('当日日线数量:', len(df_daily))
    print(df_daily.head())
else:
    print(f'{target_date} 不是交易日，跳过同步')
```

## 9. 字段设计建议（便于后端入库）

- `name`
- `fullname`
- `market`
- `list_status`
- `list_date`
- `delist_date`
- `trade_unit`
- `isin`

- `ts_code`

## 10. 开发注意事项

### 10.1 权限限制
- `hk_basic` 和 `hk_tradecal` 需要至少 **2000 积分**
- `hk_daily` 需要**单独开通权限**
- 开发前要先确认当前 Tushare 账号权限是否满足要求

### 10.2 更新时机
- `hk_daily` 每日 **18 点左右** 更新当日数据
- 建议定时任务在 **18:30 之后** 执行，避免抓到未更新完成的数据

### 10.3 单次限制
- `hk_tradecal` 单次最大 2000 条
- `hk_daily` 单次最大 5000 行
- 历史拉取时可能需要分段请求

### 10.4 同步策略建议
- 股票列表：低频同步
- 交易日历：按需同步或预拉取全年
- 日线行情：每日增量 + 历史补数双策略

---

## 11. 最终结论

如果你的目标是**获取港股日线并接入项目后端**，推荐采用以下标准流程：

1. 用 `hk_basic` 获取港股列表，建立股票池  
2. 用 `hk_tradecal` 判断目标日期是否开市  
3. 用 `hk_daily(trade_date=...)` 获取某交易日全市场港股日线  
4. 用 `hk_daily(ts_code=..., start_date=..., end_date=...)` 做历史补数  
5. 入库时以 `(ts_code, trade_date)` 作为唯一键，避免重复写入  

这套方案适合：

- 港股日线初始化
- 每日自动同步
- 后续扩展 K 线图
- 投资组合估值
- 收益统计
- 港股行情模块开发
