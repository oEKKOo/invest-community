# 2.2.2 发帖与互动实现说明

本次实现基于现有项目增量扩展，遵循“最小改动、优先复用、可持续扩展”原则。

## 已实现能力

## 1. 多样化发帖

- 新增内容类型：`NORMAL`、`LONGFORM`、`POLL`、`LIVE`
- 新增投票模型与接口：
  - `Poll` / `PollOption` / `PollVote`
  - `POST /api/posts/{id}/poll/vote/`
  - `GET /api/posts/{id}/poll/result/`
- 帖子创建/更新支持：
  - `contentType`
  - `formatType`
  - `poll`
  - `attachmentIds`

## 2. 内容交互

- 保留并复用原有：
  - 点赞（帖子/评论）
  - 收藏（帖子）
  - 多级评论（楼中楼）
- 新增：
  - 转发：`POST/DELETE /api/posts/{id}/repost/`
  - @提及：发帖/评论时解析 `@username`，落库 `Mention`

## 3. 私信增强

- 保留原有会话与消息链路
- 新增私信附件：
  - `MessageAttachment` 模型
  - 上传接口：`POST /api/uploads/messages/`
  - 发送消息支持 `attachmentIds`

## 4. 附件支持与审核

- 新增帖子附件模型：`ContentAttachment`
- 采用 Django Media/FileField（`MEDIA_ROOT`）
- 上传接口：`POST /api/uploads/content/`（multipart）
- 新增评论附件模型：`CommentAttachment`（无需审核）
- 评论附件上传接口：`POST /api/uploads/comment/`（multipart）
- 审核接口：
  - `GET /api/admin/attachments/`
  - `PATCH /api/admin/attachments/{id}/status/`
- 下载控制：
  - `GET /api/attachments/{id}/download/`
  - 附件未审核通过时限制下载（管理员/上传者例外）

## 5. 通知联动

- 扩展通知类型：
  - `MENTION`
  - `POLL_VOTED`
  - `ATTACHMENT_REVIEWED`
- 在事件总线新增订阅：
  - `mention.created`
  - `poll.voted`
  - `attachment.reviewed`

## 6. 前端改造点

- `Community.vue`
  - 增加内容类型选择
  - 增加投票表单
  - 增加附件上传并提交 `attachmentIds`
- `PostDetail.vue`
  - 展示投票并支持投票
  - 展示附件状态并下载
  - 增加转发按钮
- `Messages.vue`
  - 私信发送支持图片上传
  - 消息渲染附件链接
- `AdminPanel.vue`
  - 新增附件审核区块（通过/驳回）

## 7. 迁移与验证

- 新增迁移：
  - `content.0006_contentmeta_poll_polloption_contentattachment_and_more`
  - `notifications.0002_alter_notification_notification_type`
  - `private_messages.0001_initial`

  - `python manage.py migrate`
